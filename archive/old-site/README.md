# Архів старого сайту ВІТРАЖ

Копія попередньої версії сайту (Next.js, дані з `master` на момент 17.11.2026), збережена перед повною переробкою.

Що тут є:

- `app/` — вихідний код сторінок і компонентів (тексти, FAQ, калькулятори, категорії);
- `data/` — JSON-дані каталогів (плісе, тканинні жалюзі, дерев'яні жалюзі, рулонні штори, ціни на вікна);
- `php/` — старі обробники форм замовлень (вікна, ворота, ролети, москітні сітки);
- `public/calc/`, `public/data/` — картинки конфігурацій вікон і `price.json`;
- `public/logo.png`, `public/favicon.png` — логотип (він залишається в новому сайті);
- конфіги (`package.json`, `next.config.mjs` тощо).

Важкі зображення (≈ 400 МБ: фото тканин, жалюзі, галереї, `app/assets/images*`) сюди не копіювалися, щоб не роздувати репозиторій. Вони повністю збережені в гілці `master`:

```bash
git checkout master -- public/tkanynni public/plisse public/derevyani public/rumski
```

Цей каталог не входить у збірку нового сайту (`eslint` та Tailwind його ігнорують).
