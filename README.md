# ВІТРАЖ — новий сайт (v2)

Сайт компанії ВІТРАЖ — офіційного партнера заводу з виробництва металопластикових вікон. Стиль і структура орієнтовані на VEKA Center; каталог вікон — за зразком odp.com.ua; профільні системи та технічні характеристики взято із сайту заводу (без згадки назви заводу в текстах каталогу).

## Сторінки

| Адреса | Що це |
|---|---|
| `/` | Головна |
| `/catalog/` | Каталог вікон із фільтрами, сортуванням і цінами |
| `/catalog/<профіль>/` | Сторінка профільної системи (характеристики, опис) |
| `/calc/` | Калькулятор вартості (профіль → конфігурація → розміри → склопакет → колір → фурнітура → послуги) |
| `/about/` | Про компанію |
| `/contacts/` | Контакти та форма |

Москітні сітки, підвіконня, тканеві жалюзі, захисні ролети та ворота — позначені на головній як «скоро» (клієнт додасть пізніше).

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # статичний експорт у out/
```

Збірка — статичний експорт (`out/`), його можна віддавати з будь-якого хостингу. Форми надсилаються на `public/api/order.php` (потрібен PHP із `mail()`); адресу отримувача змініть у цьому файлі.

## Де що міняти

- `lib/site.js` — контакти, меню, назва заводу для сторінки «Про компанію»;
- `lib/pricing.js` — **ціни** (зараз тимчасові, потрібно підставити реальні) та опції склопакетів, кольорів, фурнітури, послуг;
- `lib/profiles.json` — профільні системи та характеристики;
- `lib/catalog.js` — конфігурації вікон і набір карток каталогу (генерується автоматично з профілів × розмірів × склопакетів × кольорів).

Старий сайт збережено в `archive/old-site/` (див. README там) та в гілці `master`.
