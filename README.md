# ВІТРАЖ — новий сайт (v2)

Сайт компанії ВІТРАЖ — офіційного партнера заводу з виробництва металопластикових вікон. Стиль і структура орієнтовані на VEKA Center; каталог вікон — за зразком odp.com.ua; профільні системи та технічні характеристики взято із сайту заводу (без згадки назви заводу в текстах каталогу).

## Сторінки

| Адреса | Що це |
|---|---|
| `/` | Головна: hero, категорії магазину, популярні вікна, профільні системи, наші роботи |
| `/catalog/` | Каталог вікон: пошук, фільтри, сортування, ціни, «В кошик» |
| `/catalog/<профіль>/` | Сторінка профільної системи (характеристики, опис) |
| `/calc/` | Калькулятор вартості вікна (профіль → конфігурація → розміри → склопакет → колір → фурнітура → послуги) |
| `/shop/screens/`, `/shop/sills/`, `/shop/blinds/`, `/shop/shutters/` | Москітні сітки, підвіконня, тканеві жалюзі та ролети, захисні ролети — картка з конфігуратором (розмір, колір, тканина, привід) |
| `/cart/` | Кошик (зберігається в браузері) |
| `/checkout/` | Оформлення замовлення: контакти, доставка, оплата → лист на пошту |
| `/thanks/` | Сторінка після замовлення |
| `/about/`, `/contacts/` | Про компанію, контакти |

Ворота позначені як «скоро». Заокруглень на сайті немає (правило в `app/globals.css`), палітра — з логотипа (синій, помаранчевий, лайм).

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # статичний експорт у out/
```

Збірка — статичний експорт (`out/`), його можна віддавати з будь-якого хостингу. Форми надсилаються на `public/api/order.php` (потрібен PHP із `mail()`); адресу отримувача змініть у цьому файлі.

## Де що міняти

- `lib/site.js` — контакти, меню, назва заводу для сторінки «Про компанію»;
- `lib/pricing.js` — **ціни на вікна** (тимчасові, потрібно підставити реальні) та опції склопакетів, кольорів, фурнітури, послуг;
- `lib/shop.js` — товари та **ціни** сіток, підвіконь, жалюзі, ролет (теж тимчасові); `lib/fabrics.json` — зразки тканин зі старого сайту;
- `lib/profiles.json` — профільні системи та характеристики;
- `lib/catalog.js` — конфігурації вікон і набір карток каталогу (генерується автоматично з профілів × розмірів × склопакетів × кольорів).

Старий сайт збережено в `archive/old-site/` (див. README там) та в гілці `master`.
